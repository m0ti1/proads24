# proads24 — сайт агентства интернет-рекламы

Одностраничный статический сайт: `index.html` + `css/` + `js/`, без сборки.
Дизайн построен на фирменных элементах лого: тёмный фон, синий разомкнутый круг
(#1e6fe8), зелёная стрела роста (#3ac85a), мотив сети узлов из референса.

## Как открыть

Просто откройте `index.html` в браузере — или поднимите локальный сервер:

```
python -m http.server 8000
# или
npx serve .
```

## Яндекс Карта

Карта подключена официальным **JavaScript API 3.0** Яндекса. API-ключ уже вписан
в переменную `YMAPS_API_KEY` в начале `js/map.js`.

- Если ключ протухнет или понадобится другой — замените значение `YMAPS_API_KEY`
  (новый ключ: https://developer.tech.yandex.ru/services/).
- Пока ключа нет — в блоке карты показывается аккуратная заглушка со ссылкой
  «Открыть в Яндекс.Картах» (и это штатное поведение, не ошибка).

Координаты офиса и адрес меняются в `js/map.js` (`CENTER`) и в `index.html`
(секции `#contacts` и `#map`).

## Форма заявки

Форма работает в демо-режиме: валидация, маска телефона, состояние загрузки и
экран успеха есть, но данные никуда не отправляются — черновик сохраняется в
`localStorage`. Для боевого режима подключите отправку на backend / в CRM
(место помечено комментарием в `js/main.js`, блок «Демо-режим»).

## Структура

```
index.html      — вся разметка (секции прокомментированы)
css/style.css   — дизайн-система: токены в :root, дальше по блокам
js/main.js      — меню, scrollspy, счётчики, процесс, модалка, форма
js/map.js       — Яндекс Карта (API 3.0) + заглушка без ключа
favicon.svg     — знак из лого
PRODUCT.md      — продуктовый контекст проекта
```
